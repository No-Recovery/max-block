# MAX Block

Профиль для iPhone, который блокирует сайты мессенджера MAX (`max.ru`, `oneme.ru` и поддомены), не затрагивая VK, OK и Mail.ru.

**Установка:** https://no-recovery.github.io/max-block/

Откройте ссылку в Safari на iPhone — профиль предложит установку сразу при заходе. Если окно установки не появилось, на странице будет кнопка.

Профиль фильтрует только веб-трафик (Safari и WebKit). Нативное приложение MAX не блокируется — для него нужен DNS-фильтр или VPN.

Удаление: **Настройки → Основные → VPN и управление устройством → MAX Block → Удалить профиль**.
